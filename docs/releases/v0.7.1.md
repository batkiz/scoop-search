# scoop-search v0.7.1

搜索结果现在显示已安装状态，适用于普通搜索、自动推荐和 `--fuzzy` 查询。

- 本地安装显示 `[installed: 版本]`；全局安装显示 `[installed globally: 版本]`。
- 括号内仍为 bucket 提供的版本，标记内显示实际安装版本。
- 根据安装记录中的来源 bucket 区分同名包；来源缺失时明确显示 `source unknown`。
- 支持 `SCOOP_GLOBAL`、`global_path` 和默认全局安装目录，以及无 `current` junction 的安装模式。
- 无效或不完整的安装记录不会中断搜索。

```text
'main' bucket:
    git (2.55.0) [installed: 2.54.0]
```

## 安装或更新

```powershell
scoop update
scoop update scoop-search
```

首次安装可使用：

```powershell
scoop install https://raw.githubusercontent.com/batkiz/scoop-search/master/scoop-search.json
```

提供 Windows x64 可执行文件 `scoop-search.exe` 和校验文件 `SHA256SUMS`。
