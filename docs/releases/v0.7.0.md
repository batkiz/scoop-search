# scoop-search v0.7.0

本 fork 的首个版本，提供 Windows x64 可执行文件。

## 新功能与行为变化

- **默认只搜索本地 bucket**；需要远程搜索时显式使用 `--remote`。`--local` 保留兼容。
- 默认同时搜索包名、命令名和别名，新增 `--name-only` 仅搜索包名。
- 普通搜索无结果时自动推荐相近结果；`--fuzzy` 主动模糊搜索，按相关度显示最多 10 项。
- 使用 strsim 处理拼写纠错，使用 Nucleo 支持 `rg`、`vsc` 等按顺序省略字符的查询。
- 本地 manifest 并行扫描，输出稳定排序，单个包不会因多个命令匹配而重复显示。

## 修复

- 空 bucket 不再导致提前结束搜索。
- 支持 Scoop `root_path`、`XDG_CONFIG_HOME`，并兼容旧 `rootPath` 配置。
- 支持旧式 bucket 根目录和嵌套目录；忽略无效 manifest。
- 搜索 shim 数组时只检查程序和别名，不匹配启动参数。
- 远程 bucket 请求失败会给出警告，并继续处理其他 bucket。

## 安装与使用

下载本页 `scoop-search.exe`，并用 `SHA256SUMS` 验证 SHA256。
也可通过 Scoop 安装：

```powershell
scoop install https://raw.githubusercontent.com/batkiz/scoop-search/master/scoop-search.json
scoop-search git
scoop-search --fuzzy --name-only rg
scoop-search --remote git
```

本版本的命令行接口包含默认行为变化；依赖自动远程搜索的脚本需增加 `--remote`。
